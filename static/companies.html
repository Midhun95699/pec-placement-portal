Aptitude Questions

QA train travels 360 km in 4 hours. What is its speed?▼
Speed = Distance / Time = 360 / 4 = 90 km/h
Formula to remember: Speed × Time = Distance
QIf 20% of a number is 80, what is 35% of the same number?▼
20% = 80 → Number = 400
35% of 400 = 140
QFind the odd one out: 2, 5, 10, 17, 26, 37, 50, 64▼
Pattern: 1²+1, 2²+1, 3²+1, 4²+1 ... → 64 should be 65 (8²+1)
Odd one out: 64
QA pipe fills a tank in 6 hours, another empties in 8 hours. If both open together, when will tank fill?▼
Net rate = 1/6 - 1/8 = 4/24 - 3/24 = 1/24
Time = 24 hours

Technical Questions

▼
QWhat is the difference between primary key and unique key?▼
  • Primary Key: Cannot be NULL, only one per table, uniquely identifies each row
  • Unique Key: Can have one NULL value, multiple allowed per table, also ensures uniqueness
QExplain the 4 pillars of OOP.▼
  • Encapsulation: Bundling data & methods, hiding internal state
  • Inheritance: Child class inherits parent properties
  • Polymorphism: Same method, different behavior
  • Abstraction: Hiding complexity, showing only essentials
QWhat is normalization? Explain 1NF, 2NF, 3NF.▼
  • 1NF: Atomic values, no repeating groups
  • 2NF: 1NF + no partial dependency on composite key
  • 3NF: 2NF + no transitive dependency
Goal: reduce redundancy and improve data integrity.
QWhat is deadlock? How to prevent it?▼
Deadlock: Two processes waiting for each other's resources indefinitely.

Prevention methods:
  • Lock ordering
  • Timeout and retry
  • Deadlock detection algorithms
  • Banker's algorithm

QReverse a string without using built-in functions.▼

rev = ""
for ch in s: rev = ch + rev

QCheck if a number is palindrome.▼
n = int(input())
print("Palindrome" if str(n)==str(n)[::-1] else "Not Palindrome")
QFind the factorial of a number using recursion.▼
def factorial(n):
  return 1 if n==0 else n * factorial(n-1)
print(factorial(5)) # 120

Technical Questions

▼
QDifference between stack and queue.▼
  • Stack: LIFO (Last In First Out) — push/pop from same end
  • Queue: FIFO (First In First Out) — enqueue at rear, dequeue from front
Use cases: Stack → recursion, undo. Queue → scheduling, BFS.
QWhat is a foreign key?▼
A foreign key is a column that creates a link between two tables. It references the primary key of another table, ensuring referential integrity — you can't insert a value that doesn't exist in the parent table.
QExplain TCP vs UDP.▼
  • TCP: Connection-oriented, reliable, ordered delivery (HTTP, FTP, Email)
  • UDP: Connectionless, faster, no guarantee (Video streaming, DNS, Gaming)

Technical Questions

▼
QWhat is the difference between GET and POST methods?▼
  • GET: Data in URL, limited size, cached, used to retrieve data
  • POST: Data in body, no size limit, not cached, used to send/submit data
QWhat are the types of joins in SQL?▼
  • INNER JOIN: Returns matching rows from both tables
  • LEFT JOIN: All rows from left + matching from right
  • RIGHT JOIN: All rows from right + matching from left
  • FULL JOIN: All rows from both tables
QWhat is a pointer in C?▼
A pointer is a variable that stores the memory address of another variable.
int a = 10;
int *p = &a; // p stores address of a
printf("%d", *p); // prints 10

Technical Questions

▼
QWhat is a linked list? Types?▼
A linked list is a linear data structure where elements are stored in nodes, each pointing to the next.

Types:
  • Singly Linked List: Each node points to next
  • Doubly Linked List: Points to both next and previous
  • Circular Linked List: Last node points to first
QDifference between ArrayList and LinkedList in Java?▼
  • ArrayList: Dynamic array, fast random access O(1), slow insert/delete O(n)
  • LinkedList: Doubly linked, fast insert/delete O(1), slow access O(n)
Use ArrayList for read-heavy, LinkedList for insert/delete-heavy operations.

Technical Questions

▼
QWhat is cloud computing? Name its service models.▼
Cloud computing is delivering IT resources (servers, storage, databases) over the internet on-demand.

Service Models:
  • IaaS: Infrastructure as a Service (AWS EC2, Azure VMs)
  • PaaS: Platform as a Service (Heroku, Google App Engine)
  • SaaS: Software as a Service (Gmail, Salesforce)
QWhat is REST API?▼
REST (Representational State Transfer) is an architectural style for APIs using HTTP methods:
  • GET: Retrieve data
  • POST: Create data
  • PUT: Update data
  • DELETE: Delete data
Uses JSON format. Stateless — each request contains all needed info.
